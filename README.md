# Sean-photo
## Site notes

Static site: no build step, no dependencies. Open `index.html` in a browser.

## Customize
1. Search `index.html` for the remaining `[bracketed]` placeholders (year started, camera model, favorite subjects) and replace them.
2. Replace each `<div class="ph ...">` in the gallery with `<img src="images/photo.jpg" alt="description">`.
   Resize photos to about 1800px wide and compress them (squoosh.app) before adding.
3. Edit the packages and prices in the Pricing section.
4. Swap the mailto form action for Formspree or Netlify Forms (and update the CSP `form-action` in the `<meta>` tag).

## Go live (free)
Netlify Drop, Cloudflare Pages or GitHub Pages. Later, buy a domain such as `yournamephoto.com`.

## Side-hustle tips
- Offer free or discounted shoots to build 15-20 portfolio photos.
- Use a simple contract and take a deposit. Check local rules on business licensing and taxes.
- Get written permission before posting photos of people, especially minors.
